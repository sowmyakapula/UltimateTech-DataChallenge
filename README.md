# Ultimate Technologies Data Science Challenge

## Overview
This project analyzes user behavior and operational dynamics for a ride-sharing platform using three approaches:

- Login demand analysis to understand usage patterns
- Experiment design to evaluate toll reimbursement impact
- Predictive modeling to identify factors influencing rider retention

## Part 1: Login Demand Analysis
Aggregated login data into 15-minute intervals and analyzed time-based patterns. Identified strong daily cycles with peak usage during late-night hours and higher activity on weekends.

## Part 2: Experiment Design
Proposed an A/B test to evaluate whether toll reimbursement increases cross-city driver participation. Defined key success metrics and statistical testing approach.

## Part 3: Rider Retention Modeling
Built classification models (Logistic Regression and Random Forest) to predict user retention. Found that early user engagement is a strong predictor of long-term activity.

## Key Insights
- User activity follows clear temporal patterns
- Early engagement strongly impacts retention
- Behavioral features outperform demographic features

## Tools Used
Python, pandas, matplotlib, seaborn, scikit-learn

## How to Run
Open the notebook and run all cells sequentially.
